01

Tentang Saya

Bukan programmer hebat. Seorang siswa yang benar-benar tertarik — dan sedang membangun kebiasaan.

Saya suka dua hal: coding dan membaca. Biasanya keduanya saling meminjam — satu bab buku tentang cara berpikir, satu malam men-debug fungsi yang keras kepala.

Saat ini saya siswa kelas X-4 di SMA Negeri 1 Babat, Lamongan. Di luar jam sekolah, sebagian besar waktu saya habis untuk bereksperimen di komputer: mencoba sesuatu, gagal, membaca lagi, lalu mencoba sekali lagi. Proyek yang saya unggah ke GitHub adalah jejak dari proses itu — termasuk yang belum selesai.

Saya tidak berpura-pura sudah mahir. Yang jujur: level saya masih dasar di hampir semua hal. Tapi setiap baris yang saya pahami hari ini tidak saya pahami kemarin — dan itu cukup untuk terus maju.

02

Yang Saya Pelajari

Empat teknologi yang sedang saya dalami. Levelnya saya jujur-ke-diri — bukan angka yang dibuat-buat.

  1. 01

    HTML

    Dasar

    Struktur halaman. Tag, semantic elements, dan form — fondasi yang saya pakai di hampir semua proyek web.

  2. 02

    CSS

    Dasar

    Layout, warna, dan tampilan. Sedang berlatih membuat desain yang bersih tanpa framework — seperti halaman ini.

  3. 03

    JavaScript

    Dasar

    Interaksi di browser — tombol, animasi, dan logika kecil. Masih banyak yang harus dipelajari, satu fungsi demi satu fungsi.

  4. 04

    Python

    Dasar

    Bahasa pertama yang serius saya pelajari. Sekarang dipakai untuk skrip kecil dan latihan logika — target berikutnya: proyek nyata.

* Level Dasar: paham sintaks dan bisa menyelesaikan masalah kecil. Menengah: bisa membangun proyek mandiri. Mahir: percaya diri mengajarkan ke orang lain.
